# Streakly voice (EN / RU)

Plain, calm, specific. Like a friend who keeps good notes — not a coach, not an ad.

## Rules

- Say the concrete thing: "Two freezes a month for each daily habit", not
  "Never lose your progress".
- One idea per sentence. No exclamation marks. No emoji in UI text.
- Celebrate with facts ("17 days"), not adjectives ("Amazing!").
- A miss is neutral: "Missed yesterday. Today still counts." Never shame, never red.
- English: sentence case, contractions are fine. Russian: lowercase «вы»,
  written natively — not translated word for word; avoid канцелярит
  («осуществить», «данный», «в целях»).
- Claims must be true in the code (limits, numbers, days). If a rule has a
  condition, say it.
- Buttons name the action: "Try without signing up", "Create an account" —
  not "Get started", "OK", "Continue".

## Banned (checked by `npm run lint:design`)

EN: unlock, supercharge, seamless(ly), effortless(ly), elevate, empower, oops,
dive in, any "!".

RU: прокачайте, бесшовно, упс, легко и просто, откройте для себя, любой «!».
